MHD Wattalpam app - upload this whole folder to a free website host (Netlify Drop, GitHub Pages or Cloudflare Pages).
Open the website address in Chrome on your phone, then menu > Install app / Add to Home screen.
Before moving: in the old page, Settings > Copy backup text. In the new app, Settings > paste > Restore from text.
Data stays on your phone. Download a backup file often (Settings > Download backup file).
